# Análise de Vendas e Desempenho Comercial

## Sobre o projeto

Este projeto tem como objetivo desenvolver uma análise de dados comerciais utilizando o Google Sheets, com foco na organização, tratamento e interpretação de dados de vendas.

A proposta é transformar dados em informações úteis para apoiar a tomada de decisões.

## Ferramentas utilizadas

- Google Sheets

## Etapas do projeto

- Organização e tratamento da base de dados;
- Utilização de fórmulas e funções;
- Aplicação de filtros;
- Criação de tabelas dinâmicas;
- Desenvolvimento de indicadores (KPIs);
- Criação de gráficos e dashboard;
- Interpretação dos resultados.

## Objetivo

Desenvolver habilidades práticas em análise de dados, visualização de informações e construção de indicadores comerciais.

## Status do projeto

Em desenvolvimento.
